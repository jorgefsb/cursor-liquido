# Dirección visual / Visual direction

## Plan

Paleta / palette: background #0A0A0A, surface #161616, orange #FF6B35, white #FFFFFF, muted #B7B3AD, ink #22211F on orange. Official Outfit 700 headings, Inter 400 body. Left-aligned product title and plain benefit; actual demo at right. Small official signature at top-left. One memorable element: real multicolored fluid, not an invented illustration.

```text
Desktop: [official signature         | real demo crop       ]
         [Cursor líquido            | controls + trail     ]
         [plain benefit             | actual obstacle      ]
         [version + honest caption  |                      ]
Mobile:  [official signature]
         [Cursor líquido + benefit]

         [version + caption]
```

## Critique and restraint / Revisión

The brief deliberately specifies black and orange; a generic dark SaaS card grid would hide the subject. Remove card decoration, scores, gradients and mascot. Use the existing real demo as the visual anchor. Its light obstacle panel is historical UI, not a new brand token. Explanatory player keeps readable text outside video, keyboard-visible focus, manual playback and mobile stacking. Reduced motion never starts media automatically.
